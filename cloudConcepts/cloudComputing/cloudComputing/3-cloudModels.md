## 🔒 Private Cloud

| ❌ Cons                                                     |
| ----------------------------------------------------------- |
| You're responsible for hardware **maintenance and updates** |

## 🌐 Public Cloud

> **Key difference from private cloud:** public cloud is available to the **general public**.

## 🔀 Hybrid Cloud

**Use cases**

- **Surge capacity:** a private cloud can burst into the public cloud for temporary increased demand
- **Extra security layer:** you choose which services stay in the public cloud and which go on your private cloud infrastructure

## Azure VMware Solution

**Scenario:** You already run VMware in a private cloud and want to move to a public or hybrid cloud.
Azure VMware Solution lets you run those VMware workloads in Azure with seamless integration and scalability.
