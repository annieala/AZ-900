# Azure Resource Tags 
source: https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/7-describe-purpose-of-tags

## What Are Tags?

Tags help you stay organized by adding metadata to your Azure resources.

Tags are **key-value pairs**, for example:

| Key | Value |
|---|---|
| Environment | Production |
| Owner | jane.doe@contoso.com |

---

## Resource Tag Use Cases

### Resource Management
- Locate and act on resources by workload, environment, or owner.

### Cost Management
- Group resources to report costs, allocate cost centers, and track budgets.

### Operations Management
- Group resources by availability requirements to help formulate service level agreements (SLAs).

### Security
- Classify data by security level, such as public or confidential.

### Governance
- Identify resources that align with compliance requirements.

### Workload Automation
- Visualize resources in complex deployments and automate tasks.

---

## Practical Starter Tag Set

A practical starter tag set for many teams is:

- **Environment**
- **Owner**
- **CostCenter**
- **Workload**

This set supports common day-to-day tasks such as:

- Filtering costs
- Finding service owners
- Scoping automation
